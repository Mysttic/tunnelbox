Settings

On: “Connect over RDP” opens remote desktop straight away — no file saved and no Windows warning on every connection.
Off: you get “Download .rdp file” instead — the file lands in Downloads and you open it with a double click.

On: once a day the panel asks the releases page whether a newer version exists and shows a bar above your connections. It sends none of your data.
Off: the panel connects to nothing except your own VPN tunnels.

Configuration file

Export writes every connection into one encrypted file (still protected by your master password) — good for a backup or for moving to another computer. Import replaces the current configuration; the previous one stays beside it as a .bak copy, and active connections are disconnected.
